# ExpertConnect Africa 🌍

A comprehensive professional services booking platform connecting clients with verified experts across Africa. Doctors, lawyers, tutors, accountants, developers, and more — all in one place.

## 🚀 Live Demo

Open `index.html` in your browser to view the application.

## 📋 Features

### For Clients
- **Search & Browse** — Find professionals by category, specialty, location, or keyword
- **Book Appointments** — Schedule in-person or online consultations with instant confirmation
- **Video Calls** — Connect with professionals via built-in video consultation
- **Chat** — Real-time messaging with professionals and support team
- **Online Payments** — Secure payment processing with card and EFT options
- **Reviews & Ratings** — Read and leave reviews to help the community
- **Document Upload** — Share documents with your professional before appointments
- **Invoices** — Automatic invoice generation for all transactions
- **Dashboard** — Track bookings, payments, and activity in one place

### For Professionals
- **Profile Management** — Create a detailed professional profile with services and pricing
- **Calendar Management** — Set availability and manage appointments
- **Payment Processing** — Receive payments directly through the platform
- **Analytics Dashboard** — Track bookings, earnings, and client reviews
- **Featured Listings** — Boost visibility with premium placement

### Platform Features
- **Multi-category support** — Healthcare, Legal, Education, Business, Home Services, Technology
- **Responsive design** — Works beautifully on desktop, tablet, and mobile
- **Modern UI** — Clean, professional interface with smooth animations
- **Toast notifications** — Real-time feedback for user actions
- **Modal dialogs** — Login, signup, and booking flows
- **Keyboard shortcuts** — ESC to close modals, Enter to search
